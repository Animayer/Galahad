# Galahad Discord emoji pack

36 **static PNG** emotes sliced from Ryan’s Galahad emote sprite sheet (6×6 rounded-square pixel tiles).

Preview: [https://animayer.github.io/Galahad/assets/discord-emojis/](https://animayer.github.io/Galahad/assets/discord-emojis/)

## Source

- Sheet: Ryan’s emote sheet (`1024×1024`, 6×6 grid)
- Each tile cropped tightly (rounded square + in-tile text like NANI / YIKES / BOOM — labels *under* tiles are excluded)
- Resized to **128×128** with nearest-neighbor
- Outer checkerboard corners made transparent where clean; muted blue-gray tile fill kept

This pack **replaces** the earlier animated GIF set (`wave`, `nod`, `shake`, …). Those GIFs are gone from this folder.

## Discord constraints

| Rule | This pack |
|---|---|
| Format | Static PNG |
| Canvas | 128×128 square |
| File size | Discord cap **256 KB**; these land ~28–36 KB |
| Scale | Nearest-neighbor — pixel art preserved |

Static emojis upload on any server (no boost required for static).

## Upload steps

1. Open the Discord server → **Server Settings → Emoji**.
2. **Upload Emoji** (or drag the `.png` files in).
3. Name each file to match the shortcode **without** colons (Discord adds those). Suggested names = filename without `.png` (e.g. `galahad_grin` → `:galahad_grin:`).
4. Confirm each tile is square and under 256 KB.
